# Python Sales Data Cleaner

My first Data Engineering practice project using Python.

## Features
- Removes duplicate records
- Removes invalid sales records
- Calculates revenue for each product
- Exports cleaned data to a CSV file
- Generates a sales summary report

## Technologies
- Python
- CSV
- pathlib

## How to Run
```bash
python Sales_cleaner.py
```
